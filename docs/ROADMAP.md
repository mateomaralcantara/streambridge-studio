# Roadmap propuesto

## V1 — incluida en este ZIP
- 1 teléfono ↔ 1 Browser Source.
- iPhone/Android vía navegador.
- WebRTC P2P.
- QR de emparejamiento.
- 720p/1080p/4K solicitado.
- cámara frontal/trasera.
- audio opcional.
- estadísticas básicas.
- STUN + TURN configurable.

## V1.5
- Panel multicámara en una sola sesión.
- nombres Camera A/B/C/D.
- tally rojo/verde enviado desde OBS.
- control remoto de zoom, exposición, foco y antorcha cuando la API/plataforma lo permita.
- perfiles 24/25/30/50/60 fps.
- bitrate adaptativo.

## V2
- aplicación nativa iOS + Android para acceso más profundo a cámara.
- receptor desktop (Tauri/Electron o nativo) y salida virtual camera/NDI/SRT.
- obs-websocket para escenas, mute, grabación y streaming.
- sincronización A/V y compensación de delay por cámara.

## V3 — StreamBridge Studio
- interfaz de realización propia.
- invitados remotos por enlace.
- grabación ISO local y/o nube.
- overlays, lower thirds, teleprompter y branding.
- multistream YouTube/Facebook/Twitch/RTMP.
- media server SFU para producciones grandes.
